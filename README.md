# Westside Interfaith Neighbors — Website

Public website for Westside Interfaith Neighbors (WIN), a coalition of 14 faith
communities on Portland's westside.

- `index.html` — the full site (Home, About, Events, Education, Service, Contact)
- `images/` — logo, photos, and event flyers

Deployed on Vercel. Static site for now; signup/event forms, admin panel, and
Supabase database to follow.
